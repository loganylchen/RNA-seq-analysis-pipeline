## Differential Expression Analysis Visualizations

### Combined DEG Upset Plot

**Rule:** `deg_upset_plot`

**Description:**
Generates Upset plots showing the overlap of differentially expressed genes (DEGs) identified by four different statistical tools:
- DESeq2
- edgeR
- limma-trend
- limma-voom

**Output Files:**
- `{project}/visualization/{tool}_{dataset}_upset.pdf` - Upset plot showing gene overlaps
- `{project}/DEG/{tool}_{dataset}_upset_data.tsv` - Overlap data matrix
- `{project}/DEG/{tool}_{dataset}_upset_summary.txt` - Summary statistics
- `{project}/DEG/{tool}_{dataset}_combined_degs.tsv` - Combined DEG results

**Visualization Features:**
- Bar chart showing number of DEGs unique to each tool or shared between tools
- Dot matrix showing which combinations of tools detected DEGs
- Color-coded by tool

**Key Information:**
- Shows consensus DEGs detected by all 4 tools
- Shows tool-specific DEGs
- Helps assess agreement between different statistical methods

**Combined DEG TSV Columns:**
- `gene_id` - Gene identifier
- `up_regulated_count` - Number of tools detecting gene as up-regulated (0-4)
- `down_regulated_count` - Number of tools detecting gene as down-regulated (0-4)
- `deseq2_up`, `edger_up`, `limma_trend_up`, `limma_voom_up` - Up-regulation indicators
- `deseq2_down`, `edger_down`, `limma_trend_down`, `limma_voom_down` - Down-regulation indicators

### DEG Scatterplot Comparison

**Rule:** `deg_scatterplot_comparison`

**Description:**
Creates multi-panel scatterplot figures comparing log2 fold changes between different datasets for each DEG tool. Only includes up-regulated genes detected by ALL 4 tools (consensus DEGs).

**Output Files:**
- `{project}/visualization/{tool}_{dataset}_scatterplot_comparison.pdf`
- `{project}/visualization/{tool}_{dataset}_scatterplot_comparison.png`

**Visualization Features:**
- **Scatterplot panels:** One panel per tool × dataset comparison
- **Color coding:**
  - Grey: Not significant in either dataset
  - Light blue: Significant in dataset 1 only
  - Light coral: Significant in dataset 2 only
  - Tool-specific color (e.g., red for DESeq2): Significant in both datasets
- **Shapes:**
  - Circle (16): Not significant or significant in one dataset only
  - Triangle (17): Significant in both datasets
- **Reference lines:**
  - Dashed diagonal line (y = x): Perfect correlation
  - Grey linear regression fit with confidence interval
- **Gene labels:** Top 3 most significant genes (lowest adjusted p-value) from each dataset are labeled using ggrepel

**Top Gene Selection Criteria:**
1. Genes are filtered by significance thresholds (log2FC ≥ 1, padj < 0.05)
2. Sorted by adjusted p-value (ascending)
3. For ties, sorted by absolute log2FC (descending)
4. Top 3 genes from each dataset are labeled

**Subtitle Information:**
- Number of consensus up-regulated genes
- Thresholds used
- Note about triangle shape and labels

**Use Cases:**
- Compare DEG results between discovery and validation datasets
- Assess reproducibility of fold changes across datasets
- Identify genes with consistent regulation patterns

### DEG Faceted Plot

**Rule:** `deg_faceted_plot`

**Description:**
Creates a multi-panel faceted figure showing DEG results from all 4 tools in separate panels, with the top 3 genes by log2FC labeled in each tool.

**Output Files:**
- `{project}/visualization/{tool}_{dataset}_faceted_plot.pdf`
- `{project}/visualization/{tool}_{dataset}_faceted_plot.png`
- `{project}/visualization/{tool}_{dataset}_faceted_plot_summary.tsv`

**Visualization Features:**
- **2×2 facet layout:** One panel for each tool (DESeq2, edgeR, limma-trend, limma-voom)
- **X-axis:** Mean expression (log2 baseMean)
- **Y-axis:** Log2 fold change
- **Color coding:**
  - Red (#E41A1C): Up-regulated genes
  - Blue (#377EB8): Down-regulated genes
  - Grey (#grey70): Not significant
- **Threshold lines:** Dashed lines at ±log2FC threshold
- **Gene labels:** Top 3 genes by absolute log2FC labeled with ggrepel

**Top Gene Selection Criteria:**
1. Filters to significant genes only
2. Selects top 3 up-regulated genes (highest log2FC)
3. Selects top 3 down-regulated genes (lowest log2FC)
4. Selects top 3 by absolute log2FC (overall)
5. Labels the union of these genes (up to 6-9 per tool)

**Summary Table Columns:**
- `Tool` - Tool name
- `Total_DEGs` - Total number of significant DEGs
- `Up_regulated` - Number of up-regulated genes
- `Down_regulated` - Number of down-regulated genes
- `Top_up_gene` - Gene with highest log2FC (most up-regulated)
- `Top_down_gene` - Gene with lowest log2FC (most down-regulated)

**Use Cases:**
- Compare DEG patterns across all tools in one figure
- Identify top candidate genes for validation
- Assess consistency of fold change magnitude across tools

### MA Plot

**Rule:** `ma_plot`

**Description:**
Generates MA plots (Mean vs Average) for DEG results from each tool. MA plots visualize the relationship between average expression and fold change.

**Output Files:**
- `{project}/visualization/{tool}_{dataset}_ma_plot.pdf`
- `{project}/visualization/{tool}_{dataset}_ma_plot.png`

**Visualization Features:**
- **X-axis (A):** Average expression (log2 of mean normalized counts)
- **Y-axis (M):** Log2 fold change
- **Color coding:**
  - Red (#E41A1C): Up-regulated genes (log2FC ≥ 1, padj < 0.05)
  - Blue (#377EB8): Down-regulated genes (log2FC ≤ -1, padj < 0.05)
  - Grey (#grey70): Not significant
- **Threshold lines:**
  - Horizontal dashed line at y = 0
  - Horizontal dashed lines at ±log2FC threshold

**Console Output:**
- Total number of genes
- Number of up-regulated genes
- Number of down-regulated genes
- Number of not significant genes

**Use Cases:**
- Assess expression-dependent bias
- Identify low-expression genes with large fold changes (potential false positives)
- Visualize overall DEG distribution

**MA Plot Interpretation:**
- Points should be symmetrically distributed around y = 0 for non-DEGs
- Up-regulated genes cluster above the upper threshold
- Down-regulated genes cluster below the lower threshold
- Low-expression genes (left side) often show higher variance

### DEG Summary Thresholds

**Rule:** `deg_summary_thresholds`

**Description:**
Generates comprehensive DEG summaries across multiple threshold combinations to assess robustness of results.

**Thresholds Tested:**
- **padj:** 0.05, 0.01, 0.001, 0.0001
- **log2FC:** 1, 1.2, 1.5, 2

**Output Files:**
- `{project}/DEG/{tool}_{dataset}_summary_thresholds.tsv` - DEG counts for all threshold combinations
- `{project}/DEG/{tool}_{dataset}_upset_data.tsv` - Overlap data
- `{project}/visualization/DEG_{tool}_{dataset}_thresholds_heatmap.pdf` - Heatmap of DEG counts
- `{project}/visualization/DEG_{tool}_{dataset}_thresholds_comparison.pdf` - Bar plot comparison

**Visualization Features:**
- **Heatmap:** Shows DEG counts across all threshold combinations
- **Bar plot:** Compares DEG counts between tools for selected thresholds
- **Summary table:** Complete DEG count matrix

**Use Cases:**
- Assess robustness of DEG results to threshold choices
- Identify threshold combinations that give consistent results
- Choose appropriate thresholds based on biological context

## Principal Component Analysis (PCA)

### PCA Plots

**Rule:** `pcatools_vis_database` and `pcatools_vis_database_batchcorrected`

**Description:**
Principal Component Analysis plots for quality assessment and visualization of sample relationships.

**Output Files:**
- `{project}/visualization/{tool}_{dataset}_pca.pdf`
- `{project}/visualization/{tool}_{dataset}_pca.png`
- `{project}/visualization/{tool}_{dataset}_pca_clinical_info.tsv`
- `{project}/visualization/{tool}_{dataset}_pca_batchcorrected.pdf` (batch-corrected version)

**Visualization Features:**
- Scatterplots of PC1 vs PC2, PC1 vs PC3, etc.
- Samples colored by condition (case/control)
- Sample labels
- Percentage of variance explained by each component

**Clinical Info TSV Columns:**
- Sample IDs and metadata used for coloring

**Use Cases:**
- Identify batch effects
- Assess sample clustering by condition
- Detect outliers
- Verify batch correction effectiveness

## Mime Machine Learning Analysis Visualizations

### Mime Response Analysis

**Rule:** `mime_response_analysis`

**Description:**
Trains machine learning models on discovery dataset and benchmarks on all datasets, generating comprehensive performance visualizations.

**Output Files:**
- `{project}/mime/{tool}/response_analysis/auc_comparison.pdf` - Bar plot of AUC values
- `{project}/mime/{tool}/response_analysis/roc_curves.pdf` - ROC curves for all models
- `{project}/mime/{tool}/response_analysis/pr_curves.pdf` - Precision-Recall curves
- `{project}/mime/{tool}/response_analysis/variable_importance.pdf` - Variable importance plots
- `{project}/mime/{tool}/response_analysis/confusion_matrices.pdf` - Confusion matrices
- `{project}/mime/{tool}/response_analysis/benchmark_summary.tsv` - Performance metrics table
- `{project}/mime/{tool}/response_analysis/models/` - Trained model RDS files
- `{project}/mime/{tool}/response_analysis/implementation_guide.txt` - Instructions for applying models

**Visualization Features:**
- **AUC comparison:** Bar plot comparing AUC across models and datasets
- **ROC curves:** TPR vs FPR for each model on each dataset
- **PR curves:** Precision vs Recall for each model
- **Variable importance:** Top predictors for each model
- **Confusion matrices:** Classification accuracy details

**Performance Metrics:**
- AUC (Area Under ROC Curve)
- Accuracy
- Sensitivity (Recall)
- Specificity
- Precision
- F1 Score

**Models Trained:**
- nb (Naive Bayes)
- svmRadialWeights (Support Vector Machine with radial kernel)
- rf (Random Forest)
- kknn (K-Nearest Neighbors)
- adaboost (AdaBoost)
- LogitBoost (Logistic Boosting)
- cancerclass

**Use Cases:**
- Compare ML algorithm performance
- Select best model for implementation
- Identify important predictive genes
- Apply trained models to new datasets

## Viewing and Using Results

### Quick Start

1. **View DEG overlaps:**
   ```bash
   open {project}/visualization/{tool}_{dataset}_upset.pdf
   ```

2. **Compare fold changes between datasets:**
   ```bash
   open {project}/visualization/{tool}_{dataset}_scatterplot_comparison.pdf
   ```

3. **See all tools in one figure:**

## Troubleshooting

### Empty Plots or No Genes Detected

**Symptom:** Upset plot shows no genes, scatterplot shows placeholder

**Possible Causes:**
1. Thresholds too stringent
2. Poor quality data
3. Batch effects not corrected

**Solutions:**
1. Check thresholds in config.yaml:
   ```yaml
   deg:
     log2fc: 1
     padj: 0.05
   ```
2. Try relaxing thresholds:
   ```yaml
   deg:
     log2fc: 0.5
     padj: 0.1
   ```
3. Check DEG summary thresholds to see if any DEGs were detected at all

### Low Correlation in Scatterplots

**Symptom:** Points scattered around diagonal, low r value

**Possible Causes:**
1. Different biological conditions
2. Batch effects
3. Technical variation

**Solutions:**
1. Verify datasets are comparable
2. Check PCA plots for batch effects
3. Consider using batch-corrected data

### Poor Mime Performance

**Symptom:** AUC < 0.7 for all models

**Possible Causes:**
1. Signal not strong enough
2. Wrong response variable
3. Too many features, too few samples

**Solutions:**
1. Check response variable in samples.tsv
2. Use only top DEGs as features
3. Try different ML methods
4. Check for data leakage
